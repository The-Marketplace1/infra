# Incident response

1. Confirm impact and open an incident record.
2. Check ALB, ingress, EKS, RDS, Redis, and external provider dashboards.
3. Stop automated production promotion.
4. Roll back the smallest safe change.
5. If persistence is affected, preserve evidence and follow the disaster recovery plan.
6. Communicate customer impact and recovery status.
7. After recovery, capture root cause, timeline, and preventive action.
